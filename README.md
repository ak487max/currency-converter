# 💱 Currency Converter

A responsive currency converter built using HTML, CSS, and JavaScript. It uses an API to fetch current exchange rates and allows users to convert amounts between multiple international currencies.

## 🌐 Live Demo

[View Live Demo](https://currency-converter-9c4i-git-main-self-0114.vercel.app/)

## ✨ Features

- 🌍 Convert between multiple international currencies
- 💰 Enter a custom amount for conversion
- 📡 Fetch current exchange rates using an API
- 🔄 Swap source and target currencies
- 🚩 Display currency flags for selected currencies
- ⚡ Dynamically update exchange-rate information
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API

## ⚙️ How It Works

1. Enter the amount you want to convert.
2. Select the source currency.
3. Select the target currency.
4. Click **Get Exchange Rate**.
5. The application fetches the current exchange rate through the API.
6. The converted amount is displayed on the screen.
