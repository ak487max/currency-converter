# currency-converter
## 🚀 API Integration in This Project

This project demonstrates how I integrated FlagsApi to convert value of currency of one county to currency of another  
Through this, I learned how to:
- Make authenticated API requests
- Handle JSON responses efficiently
- Manage errors and rate limits
- Secure API keys using environment variables

💡 **Learning Goal:**  
I built this feature to deepen my understanding of API workflows — from request/response cycles to data handling — and to apply these skills in real-world scenarios.
